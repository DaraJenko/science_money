Gitのインストール

OSによってインストール方法が異なります。

Windows

Git公式サイトからインストーラーをダウンロードして実行します。
インストール中の設定項目は基本的にデフォルト(初期設定)のままで問題ありません。
インストールすると「Git Bash」というターミナルアプリも入るので、以降はこれを使うとよいです。
※ターミナルとは、コマンドでパソコンを操作するためのものです。

macOS

Homebrewが入っていれば、ターミナルから次のコマンドでインストールできます。
※Homebrewとは、ソフトウェアのインストールやアップデートをまとめて管理できるパッケージマネージャーというものです。 

brew install git

Homebrewを使わない場合は、Xcodeのコマンドラインツールを入れるとGitも使えるようになります。
※Xcodeとは、統合開発環境(アプリを開発したりテストなどするためのもの)の1つで、
　そのコマンドラインツールとは、Xcode本体をインストールしなくても、
　ターミナルでgitなどのコマンドを実行できるようにするツールです。 

xcode-select --install

Linux（Debian / Ubuntu系）

sudo apt update
sudo apt install git
NOTE 本シリーズのコマンドはすべてターミナル（コマンドライン）上での操作を前提にしています。
GUIツールに慣れている方も、コマンドで一連の流れを覚えると、後々どのツールでも使えると思います。

インストールの確認

ターミナルで以下を実行し、バージョン番号が表示されればインストール成功です。

git --version
# 例: git version 2.45.2

名前とメールアドレスの設定

Gitを初めて使うときは、最初に一度だけ自分の名前とメールアドレスを登録します。
ここで設定した情報が、以降作成するcommitの「作者」として記録されます。 

git config --global user.name "your name"
git config --global user.email "your@email.com"

正しく設定できているかは、以下のコマンドで確認できます。

git config --list
POINT --globalを付けると、そのPC上のすべてのリポジトリに共通の設定として登録されます。
仕事用と個人用でメールアドレスを使い分けたい場合は、各リポジトリのフォルダ内で
--globalを付けずに実行すると、そのリポジトリだけの設定として上書きできます。

デフォルトブランチ名の設定

git initで新規リポジトリを作ったときに最初に作られるブランチの名前は、
Gitのバージョンや設定によってmasterまたはmainになります。
現在はGitHub側の標準に合わせてmainにしておくのが一般的です。 

git config --global init.defaultBranch main

※リボジトリ：履歴を格納しておく場所(フォルダ)
※ブランチ：履歴を分岐させるもの。mainブランチは履歴の本流。

エディタの設定

commitメッセージをコマンドに直接書かず、エディタを開いて入力したい場合や、
コンフリクト解決時にエディタが自動で開くようにしたい場合は、使用エディタを指定しておきます。
例としてVS Codeを指定する場合は以下の通りです。 

git config --global core.editor "code --wait"

特にこだわりがなければ、この設定はスキップしても問題ありません。
※commitメッセージ：履歴を記録する際に、変更理由を記載できる。
※エディタ：メモ帳など、プログラムを書くためのツール。
※コンフリクト：異なるブランチのcommitを統合する際に、同じ箇所で異なる変更がされていた場合、
　どちらの変更を優先すべきか自動で判断できず停止すること。

GitHubアカウントの準備

次回以降、リモートリポジトリの操作も扱うので、まだアカウントを持っていない場合は
GitHubで無料アカウントを作成しておきましょう。

GitHubにpushする際の認証方法として、以前はユーザー名とパスワードでの認証が使われていましたが、
現在はPersonal Access Token（PAT）またはSSH鍵を使う方式が主流です。
設定手順はGitHubの公式ドキュメントが最も正確かつ最新なので、アカウント作成後に
「GitHub SSH key 設定」などで検索し、ドキュメントに沿って設定しておくとスムーズです。

NOTE SSH鍵は一度設定すれば以降はpush・pullのたびにパスワードを聞かれなくなります。
この設定は次々回（⑤）までに済ませておけば大丈夫です。

※push：リモートリポジトリにローカルリポジトリの更新を反映させること
※pull：ローカルリポジトリにリモートリポジトリの更新を反映させること

まとめ
